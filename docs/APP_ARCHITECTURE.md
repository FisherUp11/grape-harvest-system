# 收葡萄系统 · 应用架构与维护说明

最后更新：2026-10-17。

本系统服务于多个隔离的葡萄农场，使用“葡萄”代称资金。承诺支持、实际收到与实际使用分开记录，管家确认或符合农场规则自动生效的固定支出才参与余额和月报。

## 架构与职责

- Next.js 14 App Router + React 18 + TypeScript。保留现有技术栈，不引入独立后端或 UI 框架。
- `page.tsx` 在服务端鉴权、读取数据，`XxxClient.tsx` 处理表单与交互。
- `lib/supabase/server.ts` 通过 `getUser()` 验证身份；`getAppContext` 使用 React `cache` 在同一次服务端请求中复用鉴权结果。
- `lib/data.ts` 统一处理查询失败与分批读取，避免数据库默认返回行数上限使余额只计算部分记录。失败会进入错误页，不转换为空记录。
- `lib/report.ts` 使用整数分累计金额，统一月初、本月、月末与当前余额口径。月报的月末余额截止于所选月份。业务日期与时间统一按北京时间显示，报告生成时间由服务端传入，避免服务端/浏览器时区差异。
- Supabase PostgreSQL 的 RLS 限制归属与机构，触发器处理锁定、关联同步、预算流转与审计；客户端显隐只负责交互体验。
- Supabase Storage 私有凭证桶按 `owner_id/consumption_id/UUID_filename` 保存文件，使用临时签名链接读取。

## 角色

`profiles.role` 为 `super_admin`（葡萄总园主）、`grape_keeper`（农场管家）、`user`（记录者）。总园主全局只读业务，创建农场、创建账号及分配角色；其现有历史仍保留原归属。管家只管理本农场，每个农场最多两位，可以登记自己的业务，但不能代改其他人的金额。普通用户只读写自己的业务。支持者是联系人记录，没有登录账号。

账号管理 API 每次验证 Auth 身份及数据库角色，不信任用户可编辑 metadata。临时密码使用加密随机数，仅在邮件中发送，不返回给浏览器、不进入日志或审计。首次改密状态由 Auth 密码更新触发器解除；重发轮换服务端 onboarding_nonce 和密码，继续强制改密。未改密前 RLS 也阻止业务访问。邮件失败保留账号并标记失败，可重发，不重复创建。

`getSessionContext` 可读取首次改密资料；业务页面使用 `getAppContext` 跳转改密。账号角色变更使用受控 RPC，防止越权、第三位管家及移除最后的总园主。已有历史的账号不允许直接跨农场移动，避免历史记录错归属。

## 业务一致性

1. 承诺和期次在单个 invoker RPC 事务中创建；收款动作由数据库原子同步期次，禁止直接修改期次的实际金额或审核字段。
2. 收款、支出及更正单使用 `draft → pending → confirmed`；管家可将 pending 退回 returned（必须原因），本人修改后重提。pending 不可自行改动或删除，confirmed 永久不可修改、退回或删除。
3. 固定支出默认自动生效，管家可开启本农场审核；项目、一次性及更正单强制人工审核。首次提交保存审核规则快照；后续设置变动不改变历史提交的规则。
4. 确认记录发生错误时，原单保持原样，另提更正单，填更正后应有金额和原因。系统取最新有效金额作为基数；管家确认时串行核验，拒绝基于过时基数的重复更正。只有差额在更正日期参与余额、支持者统计、预算执行及月报。
5. 预算待审核不能自行撤回；管家填写原因退回后可改。确认预算不可解锁；复制为新版本重新审核。禁止其他生效预算重叠或同一原版多个分支同时生效，新记录使用最新确认版本；科目沿版本谱系累计同一预算期内的历史支出，不能将已发生支出的科目直接删除。
6. 文本作废采用软删除，保留原字段、作废人、时间和原因。审计由私有数据库触发器写入，更新仅记录有变化字段（忽略更新时间/上传技术标志），不复制图片、密码或凭证二进制；浏览器无写入或删除审计权限。
7. 每条支出至少一个、最多五个凭证。上传元数据锁父记录并验证归属、路径和大小；已提交凭证不可改，确认后的 Storage 文件不可删。作废草稿清理文件时仍保留文字资料与审计。

## 图片清晰度与上传

`lib/imageCompression.ts` 在浏览器选择文件后处理图片；逐张处理减少手机内存峰值。

- 普通图片：最长边 2560px，JPEG 质量 0.88，不放大小图；压缩后更大时保留原文件。
- 长票据：尽量保留短边，限制短边 1600px、长边 8000px，避免只按普通长边规则把小字压得过小。
- 透明图片转 JPEG 时先铺白底。
- 展示原始/上传大小和像素尺寸，提供放大预览，可选择保留原图。压缩不能保证所有极小文字都清晰，提交前应核对；不清楚时使用原图。
- 图片源文件最多 30MB；实际上传的单文件仍最多 8MB，PDF 原样保留。浏览器无法解码的 HEIC/HEIF 会保留原文件并提示，超过 8MB 则要求转换/拆分。
- 每条记录至少 1 个、最多 5 个凭证。草稿或退回记录可补充凭证；已提交记录的凭证锁定。
- 上传期间 `attachments_ready=false`，数据库禁止管家确认半上传记录；全部完成后才置为 true。失败时尝试回滚本次文件和元数据，清理失败会明确提示，不能保证跨数据库/对象存储的分布式事务。

## 空间统计

`StorageUsage` 显示实际字节数、文件数、更新时间；管家还可查看配置容量、剩余空间与百分比。首页、支出页、设置页均可查看；手机全部功能菜单也有紧凑显示。

可见页面每 30 秒刷新，重新聚焦和上传/删除完成后立即请求刷新。失败显示错误并保留上次读数，不显示假零。

`get_storage_usage_summary` 是需要读取 `storage.objects` 的受控 definer 函数：检查当前身份和机构，普通用户只统计自己，管家只统计当前机构凭证桶。不统计其他业务桶；容量来自 `NEXT_PUBLIC_SUPABASE_STORAGE_QUOTA_GB`，代表本应用配置的附件额度，并非 Supabase 平台实时套餐查询。

总园主 `get_estate_capacity` 检查实时角色，只返回大小、数量和农场概况，不暴露对象内容；包含实际数据库大小（系统占用也计入）、审计表与索引大小、全项目文件和逐农场附件。`NEXT_PUBLIC_DATABASE_QUOTA_MB` 默认 500；文件默认 1GB。配额是参考，并非平台套餐实时查询。

`/api/admin/export` 再次鉴权，仅总园主可取 gzip JSON，含业务文字、软删除历史和附件元数据，不含 Auth、密码、密钥和图片。审计分页每页 50 条，按日期导出归档；不自动清除。20 人文本量通常较小，实际增长以容量页为准，图片单独占文件额度。

## 每日检查与邮件

`app/api/cron/daily/route.ts` 为服务端任务入口，使用 `CRON_SECRET` 验证请求，`SUPABASE_SERVICE_ROLE_KEY` 只在服务端使用。`vercel.json` 配置每天 UTC 00:30（北京时间约 08:30）触发；具体执行时间与平台调度精度有关。

- 不配置邮件时：计算用户余额与低存量人数，返回检查结果，不发送邮件。
- 配置 `RESEND_API_KEY`、`MAIL_FROM`、`NEXT_PUBLIC_SITE_URL` 后：向低存量用户及同机构管家发送提醒，日内按用户去重。
- `ENABLE_MONTHLY_REPORT_EMAIL=true` 时：每天补发当前月尚未成功发送的上月摘要。摘要有月初、本月收支、月末存量和登录后的报告入口。**不附 PDF 文件**，PDF 仍通过报告页打印保存。
- `notification_deliveries` 保存发送成功记录，浏览器无法访问；Resend 请求还带幂等键。服务商幂等窗口有限，发送成功但账本写入失败时需要核对部署日志，不能宣称绝对不会重复发送。
- 未配置任务密钥或服务端密钥不能启用线上定时检查；设置页只显示配置就绪状态，不将其当作已执行成功的证明。

固定吃葡萄当前保留人工登记：固定用量可在表单快捷填入，实际发生日期、预算科目和凭证仍需记录者核对。自动无凭证生成实际支出会与当前凭证规则冲突，不在本次默认启用。

## 数据库复查说明

本轮已固定历史函数搜索路径，撤销匿名角色对身份辅助函数的执行权，并将 RLS 中与行无关的身份查询改为语句级计算。总园主分配与容量函数必须使用受控 definer 权限，均在函数内部校验实时数据库角色，保留给登录客户端调用是预期设计（[Supabase 受控函数复查说明](https://supabase.com/docs/guides/database/database-linter?lint=0029_authenticated_security_definer_function_executable)）。

通知去重表没有浏览器 RLS 策略且撤销 anon/authenticated 权限，仅服务端任务访问，属于默认拒绝。平台仍提示未启用[泄露密码保护](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection)，本次未变更套餐或 Auth 平台开关。未使用索引、历史审核人/作废人外键索引等为性能提示；当前小规模记录不批量增加无查询收益的索引，后续按实际查询计划调整。
